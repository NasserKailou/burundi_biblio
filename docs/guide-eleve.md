# Guide élève

## Créer un compte

Depuis la page de connexion, cliquez sur **Créer un compte**. Renseignez
votre nom, prénom, un identifiant (unique), votre niveau, votre classe
(optionnel) et un mot de passe. Selon la configuration de
l'établissement, votre compte devra être validé par un administrateur
avant votre première connexion (message affiché après l'inscription).

## Le catalogue

Menu **Catalogue** : grille des couvertures des manuels de votre niveau
et des ressources marquées "Commun" (accessibles à tous les niveaux).
Utilisez la barre de recherche (titre/auteur/mot-clé) et le filtre par
matière pour affiner. Cliquez sur une couverture pour voir la fiche du
manuel, puis sur **Lire** pour ouvrir le lecteur.

## Le lecteur

- **Pages** : flèches précédent/suivant (ou flèches du clavier).
- **Zoom** : boutons + / − dans la barre d'outils.
- **Plein écran** : bouton dédié.
- **Signets** : marquez une position pour y revenir rapidement (stockés dans votre navigateur, pas sur le serveur).
- **Favoris** : l'étoile ajoute/retire le manuel de vos favoris.
- Votre position de lecture est enregistrée automatiquement — à la réouverture d'un manuel déjà commencé, vous reprenez où vous vous étiez arrêté.

## Mon espace

Menu **Mon espace** : retrouvez vos manuels en cours de lecture
("Reprendre la lecture"), vos favoris, et votre profil.
