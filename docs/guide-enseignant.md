# Guide enseignant

## Ajouter un manuel

Menu **Mes manuels** → **Ajouter un manuel**. Renseignez le titre, la
matière, l'auteur/année (optionnels), sélectionnez le ou les niveaux
cibles (limités aux niveaux qui vous sont attribués), et téléversez le
fichier (PDF ou EPUB) et une couverture (image).

- Si un administrateur vous a accordé le droit de publier des ressources
  **communes**, une case à cocher "Ressource commune" apparaît — cochez-la
  pour rendre le manuel visible par tous les niveaux, pas seulement les
  niveaux sélectionnés.
- **Statut** : choisissez "Brouillon" pour préparer un manuel sans le
  rendre visible aux élèves, ou "Publié" pour le rendre immédiatement
  accessible.
- Le fichier est vérifié par son contenu réel (pas seulement son
  extension) : un fichier renommé `.pdf` mais qui n'est pas un vrai PDF
  sera refusé.

## Gérer mes manuels

La liste **Mes manuels** affiche uniquement vos propres ressources
(celles téléversées par vous), avec le nombre de consultations reçues.
**Modifier** permet de changer les métadonnées ou remplacer le
fichier/la couverture (laisser le champ vide pour conserver l'existant).
**Supprimer** retire définitivement le manuel et son fichier.

Vous ne pouvez pas modifier ou supprimer les manuels d'un collègue, même
s'ils ciblent un niveau que vous partagez.

## Statistiques

Menu **Statistiques** : tableau de bord limité à votre/vos niveau(x) —
consultations dans le temps, répartition par matière, manuels les plus
consultés et élèves les plus actifs de votre périmètre.
